## 渲染调整

| 项目 | 原值或绘制位置 | 本次值或绘制位置 | 原因 |
| --- | --- | --- | --- |
| 世界缓冲 | `AFTER_TRANSLUCENT`，区块半透明层 | `AFTER_ENTITIES`，实体用的半透明方块图集 | Fabric 在前一回调不提供可提交的世界顶点缓冲。新增模型、移除框和文件框需要写入本帧会绘制的缓冲。 |
| 新增模型 | 顶点 RGB 直接透传 | 每个通道乘以 `0.5 + 0.5 × preview-add 通道 / 255` | 让纹理保留原材料和明暗，同时读到主题的新增色。 |
| 移除轮廓 | 向内缩 0.02 格；主次 alpha 0.90 / 0.35 | 向外扩 0.006 格，主次 alpha 0.95 / 0.55 | 待移除的实心方块仍在世界里，内侧线会被表面遮挡。0.03 格的文件外框与移除框仍有间隔。 |
| 无模型的新增方块 | 和移除块共用移除色 | 使用 `preview-add` 画框 | 让流体等没有普通方块模型的新增项仍表达正确操作。 |
