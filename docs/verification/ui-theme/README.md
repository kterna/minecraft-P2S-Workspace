## 验证记录

- Java 21 一次构建了 1.21 和 1.21.1。两个版本分别运行 170 项测试，全部通过；其中各有 7 项主题测试。已逐一打开生成的 JAR 核对内置 JSON，其内容与 `docs/mockups/gpt/themes.json` 逐字节一致。
- 在同一游戏实例中准备了有历史消息、两个待审文件及未发送草稿的会话。通过设置的「外观」按钮依次切换主题，核对每一套的配置 ID、面板像素与实际剪贴板中的草稿。用鼠标滚轮改变消息位置后，余烬 → 冰川 → 陶笺 → 余烬一轮的滚动视口像素哈希与切换前一致。
- 实际执行了 `/p2s theme <id>` 和 `/p2s theme reload`。坏玩家文件中 `accent` 的非法值触发带文件名和字段名的游戏聊天与日志提示，当前陶笺配色继续生效。
- 在玩家目录新增主题、覆盖内置陶笺，并验证缺省 `inset` 取自余烬。三种预期的面板颜色均在实际截图中找到。移除测试文件再重载后恢复内置陶笺，客户端已正常退出。

当前游戏仍使用原有布局。在本次截图的尺寸下，聊天页顶栏仍有重叠。原型下排展示其外观弹出菜单，游戏下排展示目前的通用设置页。八套数据均有自动测试；本次逐帧实机对照集中于表中的三套。
